# Block Frames

A Better Than Adventure mod that adds frame blocks that can take on the texture of others.

## Tools
- Frame Hammer:
  - Allows you to remove the texture of a frame block without breaking it
- Frame Wrench:
  - Lets you switch which texture from a block the frame block will use (eg. choosing between the top and side of a log)
